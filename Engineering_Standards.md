
# Engineering Standards

## Language
Python 3.12+

## Architecture
- dependency injection where appropriate
- clean interfaces
- typed schemas
- configuration driven
- modular packages

## Persistence
Persist:
tasks
strategies
workflows
experiments
reviews
analytics
UI state
memory

## Logging
Every important event:
timestamp
task id
tool
duration
cost
evaluation
reflection

## UI
FastAPI
React (or simple frontend)
WebSockets

## Working Summary

Never expose hidden reasoning.

Show:
current goal
plan
assumptions
blockers
next step
recent observations

Maintain rolling summary.

## Quality

Every feature:
- unit tested
- documented
- observable
- configurable
- restart safe

## Cost

Track:
tokens
latency
provider
model
cost

Optimize routing continuously.

## Acceptance

Prefer simple, boring, maintainable implementations over clever complexity.
